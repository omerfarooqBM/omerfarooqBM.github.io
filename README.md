# omerfarooqBM.github.io

Portfolio site for Omer Farooq, Software & AI Engineer: https://omerfarooqbm.github.io

Plain HTML, CSS and JavaScript, served by GitHub Pages. No build step.

## Edit

- **Projects, services and text:** `index.html`. Project details for the pop-up live in the `window.PROJECTS` script near the end.
- **Upwork link:** set `LINKS.upwork` at the top of `assets/js/main.js` to show the "Hire me on Upwork" buttons.
- **Images:** `assets/img/projects/` (4:3, 960 × 720) and `assets/img/og.png` for link previews.
- **Live stats:** the terminal, activity and contribution-city cards load from [omerfarooqBM/omerfarooqBM](https://github.com/omerfarooqBM/omerfarooqBM), which refreshes them twice a day.

## Publish

Push to `main`. In **Settings → Pages**, the source should be **Deploy from a branch**, branch `main`, folder `/ (root)`.
